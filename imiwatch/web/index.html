        判定モデル
        
        
        
        見張りごとに、別の判定モデルを選ぶこともできます。
        
        
        Cloudflare（Clef / Clef-flash）
          
          
          
        
        
        
        
        jev-local（imajev-4b・自前サーバー）
          
          
          
        
        
        
        
        Perplexity Decisions API
          
          
          
        
        
        
        
        SystemOne 互換（TypeSafe Jev など）
          
          
          
          
          
        
        
        
      
        

      
        
        
        設計役の LLM
        
        
        知りたいことを観点に分けるときと、「LLM で代用」の判定に使います。OpenAI 互換（/chat/completions）と Anthropic 形式（/v1/messages）のどちらにも対応しています。
        
        
        
        
        
        
        
        
        
        
        
        
      
        

      
        
        
        画像と記録
        
        
        
        
        前回の撮影との差がこれより小さければ、判定を省いて前回の値を使います（API の利用を減らせます）。
        
        
        
        
        
        
      
        

      
        
        
        このアプリ
        
        
        
        
        判定は完璧ではありません。見逃しや誤った通知は起こりえます。防犯や安全、お金に関わる用途には使わないでください。
        
        
        選んだ範囲の画像は、選んだ判定モデルの提供元（設計時は設計役の LLM）に送られます。jev-local を使えば、判定の画像は自分のサーバーの外に出ません。
        
        
        
      
        
    
        
    
        
      鍵の欄は、空欄のままなら変更しません。
